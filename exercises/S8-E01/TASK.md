# S8-E01：检查受试者划分是否互相独立

目标：训练前先验证三组受试者名单无交叉，且恰好覆盖DEAP的1至32号受试者。本题不加载脑电、不训练模型、不修改研究入口。

这次按用户2026-10-23“教我做”的请求，从受试者级评估的第一小步开始；此前S1-E01仍未提交，不视为通过。

在同目录check_split.py中补全validate_subject_split。输入为三份整数列表；合法时返回True，非法时抛出ValueError。

必须检查：每组非空、每组内部无重复、任意两组无交叉、三组合起来恰好为1至32。使用set、len、集合交集（&）和并集（|）。
