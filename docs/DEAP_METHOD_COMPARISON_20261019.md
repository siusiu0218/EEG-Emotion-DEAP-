# DEAP Valence 方法对照：别人怎样训练和考试

核对日期：2026-10-19。本次只查论文作者原文、作者代码与复现框架作者自己的报告；没有训练、改模型或提交集群任务。以下数字是不同“考试规则”的结果，不能直接排榜。

## 先给新手的结论

别人确实报告过 90% 以上，但往往是“每个人单独练一个模型”，并且预处理、切片和分组都不同。也有认真隔开整段试验、或者隔开人的实验，只得到约 50%—60%。因此，单看 69.93% 还不能判定我们的实现差在哪里，更不能据别人的 95% 保证改完就能达到。

三种考试要分开：**片段分开**，同一分钟的脑电可同时进入训练和验证；**整次试验分开**，一整分钟只进一边；**人分开**，考试的人完全没参加训练。后两种也彼此不同。

## 别人具体做了什么

**TSception** 直接从时域脑电学习时间和左右半球模式。使用 DEAP 预处理版，去掉前 3 秒、重排并保留 28 通道，切成 4 秒；代码用外层训练数据的均值/标准差逐通道标准化。外层按试验分测试，内层把剩余片段按类别划成 80/20 训练/验证，500 轮选最佳验证模型。它保护了外层测试试验，但不应说内层验证也完全按试验隔离。[作者数据代码](https://github.com/yi-ding-cs/TSception/blob/main/code/prepare_data_DEAP.py)、[分组与标准化代码](https://github.com/yi-ding-cs/TSception/blob/main/code/cross_validation.py)、[参数入口](https://github.com/yi-ding-cs/TSception/blob/main/code/main-DEAP.py)。

**DWT + SVM** 用 db4 四级小波提取四频带的能量和熵，32 通道共 256 个特征，再做 RBF-SVM。重要区别是：先分别算刺激期和前三秒静息期的特征，再相减；我们当前则先在波形上扣基线，再提取 DE。两者不是同一个操作。3 秒窗互不重叠，单人 SVM 使用 C=200、gamma 按特征数与方差缩放。论文 Table 4 的 95.32% 有原文依据，但没有核实作者可运行代码及独立复现，也没有证据说明完整试验在各折间隔离。[作者论文](https://arxiv.org/pdf/2110.05635)。

**LGG 作者代码可借鉴的做法** 是 4 秒窗口、逐人模型、外层按试验 10 折、用外层训练集统计量标准化；内层另做片段划分。其代码删除前三秒而不是做当前波形基线扣除，标签 `<=5` / `>5` 也与本地不同。本次不援引 LGG 准确率。[参数](https://github.com/yi-ding-cs/LGG/blob/main/main-DEAP.py)、[分组与标准化](https://github.com/yi-ding-cs/LGG/blob/main/cross_validation.py)、[预处理](https://github.com/yi-ding-cs/LGG/blob/main/prepare_data_DEAP.py)。

## 对本项目的下一步建议（尚未执行）

1. 先保持现有验证分组，建立“只改一个地方”的对照。可优先评估**由训练集拟合、再应用到验证集的逐通道标准化**，与当前基线比较；这只是有出处的候选，不是已经证明能涨分。
2. 之后再单独对照更长窗口或基线特征扣除。当前 `calculate_ae` 按完整窗口切分前三秒基线，窗口超过 3 秒时会得到零个基线切片；直接设 `--time_window 4` 就会触发这一问题，因此必须先设计并验证基线处理，不能照抄别人的 4 秒参数。改窗口必须使用新缓存，不覆盖原始数据；不要把窗口、标签、模型和学习率同时换掉。
3. 当前 1 秒输入与默认 `n_slices=1` 尚未验证多窗口时序建模；这是需要明确的模型行为，不能直接断言为 69.93% 的原因。
4. 追求接近作者流程和评估新人的能力是两个任务。前者可继续做同规则对照；后者另建按人隔离实验。任何提高都应注明是哪种考试。

## 未核对及引用边界

- 本次查阅原文与公开代码，未复跑任何外部模型；未锁定外部仓库提交，后续实施前需要冻结版本。
- DWT 论文摘要提到 80.70%，正文 Table 3 对应的是 **5 通道、3 秒**；不能误写成完整 32 通道的成绩。主比较采用原表明确的通道和窗口。
- DWT 混人分层交叉验证并未提供 LOSO 证据，调参是否完全嵌套在外层训练折也未核实，不能据此称其跨人泛化已达到 83.79%。
- EEGain 第 6 节列出 TSception LOTO 原表 Valence ACC 62.27 / F1 65.37，其自己的复现为 ACC 59.32 / F1 62.49；这是 EEGain 团队自己的复现，不是 TSception 作者原始结果，也不是本地结果。
- 69.93% 是本地最佳验证结果，没有独立留出测试集；上述文献不能单凭分数给它判“好”或“差”。
